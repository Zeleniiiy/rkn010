# Открытые решения перед полной боевой миграцией

Код и dry-run готовы с текущими правилами, но перед полной записью на PROD необходимо подтвердить:

1. Полный перечень обязательных полей `subject`. Сейчас проверяется известный минимум, остальные данные копируются из `organizations`.
2. Колонки начала/окончания действия лицензии. Пустые даты не трактуются как бессрочность.
3. Механизм переноса файлов приказов и экспертных заключений. В v1 новые файлы не загружаются.
4. Числовой порядок истории по регистрационному номеру; dry-run показывает его для ручной сверки.
5. Пропущенные исходные строки и конфликты наименований/ОГРН до финального файла.
