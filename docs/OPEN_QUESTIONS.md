# Открытые решения перед полной боевой миграцией

Код и dry-run готовы с текущими правилами, но перед полной записью на PROD необходимо подтвердить:

1. Источник недостающих реквизитов субъектов. Часть карточек `organizations`, включая тестовую карточку ПАО «Ростелеком», не содержит ИНН, ОПФ, юридический/фактический адрес, телефон и email. Скрипт теперь блокирует такую запись, а не выдумывает значения.
2. Колонки начала/окончания действия лицензии. Пустые даты не трактуются как бессрочность.
3. Нужно ли переносить процессные метаданные ручных реестровых записей (`xsd`, `titles`, `registryParams`). Их идентификаторы могут различаться между стендами; `appealEntryId` у миграционных записей отсутствует по определению.
4. Числовой порядок истории по регистрационному номеру; dry-run показывает его для ручной сверки.
5. Пропущенные исходные строки и конфликты наименований/ОГРН до финального файла.
