# Авторизация по контурам

Для каждого стенда используется отдельная пара файлов:

- `auth/<profile>/token.md` — JWT целиком, с `Bearer` или без него;
- `auth/<profile>/cookie.md` — значение заголовка Cookie целиком;
- `auth/<profile>/ca.pem` — необязательная доверенная CA-цепочка стенда.

Штатные профили:

- `dev` — контур разработки;
- `psi` — тестовый контур ПСИ;
- `prod` — промышленный контур;
- `custom` — заготовка для дополнительного стенда с обязательным `--base-url`.

После клонирования выполните `scripts/bootstrap.ps1`: скрипт создаст
отсутствующие `token.md` и `cookie.md`, но не изменит уже заполненные файлы.
Также можно скопировать соответствующие `*.example.md` вручную, убрав
`.example` из имени.

Реальные Cookie, JWT и `ca.pem` игнорируются Git. Не добавляйте секреты в
примеры, команды PowerShell, журналы, коммиты или скриншоты.
