# Входные файлы миграции

Каталоги разделены по стендам:

- `input/dev`;
- `input/psi`;
- `input/prod`;
- `input/custom`.

Excel-файлы внутри этих каталогов являются локальными рабочими данными и не
попадают в Git. При запуске миграции передавайте полный путь к выбранной книге
через параметр `--workbook` либо `-Workbook` в PowerShell-обёртках.

Не используйте один каталог запуска `runs` для разных контуров и не переносите
`checkpoint.json` между профилями.
